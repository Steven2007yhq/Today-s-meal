# 好吃的今天 1.2.0

构建日期：2026-08-26

## 本次更新

- 服务端中华菜品库扩展至 5,000 道已发布菜品，支持菜名、食材、做法和近似菜名搜索。
- 新增 73 张类别基准图；专属图与保守同类图合计覆盖 3,894 道菜，并明确标注同类示意图。
- 支持以一种或多种现有食材克数反推其余配料；多食材使用可解释的相对加权最小二乘拟合。
- 菜品详情改为可关闭的侧边抽屉，支持 Esc 关闭、焦点返回和减少动态效果。
- 正文、表单和按钮建立 12px 可读性下限，提升辅助文字、焦点环和操作按钮对比度。
- 菜品库组件与样式从主应用文件拆分，并完成 100%、125%、150% 缩放验证。
- README 使用说明和官网入口更新至当前产品状态。

## 交付说明

- 本安装包为 Windows 10 / 11 x64 封闭测试版本。
- 当前构建未配置 Windows 代码签名证书，首次运行时系统可能显示未知发布者提示。
- 5,000 道完整目录、在线图片、账号、云端收藏和小饭 AI 需要后台服务；离线时保留基础菜品、餐食记录和日历能力。
- 营养与小饭 AI 建议仅作日常饮食参考，不替代医生或营养师。
